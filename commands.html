Homelab Command Reference

SSH Access

Connect to Raspberry Pis and servers remotely.

  • ssh daniel@IP_ADDRESS
    Connect to a device using SSH
  • hostname -I
    Display the current device IP address
  • hostname
    Display the device hostname

Linux System Updates

  • sudo apt update
    Refresh available package lists
  • sudo apt upgrade -y
    Install available updates
  • sudo reboot
    Restart the device

System Health

  • df -h
    Check disk space usage across all drives
  • free -h
    Check memory (RAM) usage
  • vcgencmd measure_temp
    Check the Raspberry Pi's CPU temperature
  • htop
    Interactive view of running processes and resource usage (press q to quit)

Docker Commands

  • docker ps
    Show running containers
  • docker ps -a
    Show all containers, including stopped ones
  • docker logs CONTAINER_NAME
    View container logs
  • docker restart CONTAINER_NAME
    Restart a container
  • docker compose up -d
    Start services defined in a Docker Compose file
  • docker compose up -d --build
    Rebuild the image and start services (use after editing code, not just config)
  • docker compose down
    Stop and remove services defined in a Docker Compose file
  • docker compose logs -f
    Follow live logs for a service (Ctrl+C to stop watching)
  • docker system prune
    Remove unused containers, networks, and images to free up disk space

NGINX Commands

  • sudo nginx -t
    Test NGINX configuration
  • sudo systemctl restart nginx
    Restart NGINX
  • sudo systemctl status nginx
    Check NGINX status
  • sudo nginx -T
    Display the complete NGINX configuration

Pi-hole Commands

  • pihole status
    Check Pi-hole status
  • pihole -up
    Update Pi-hole
  • pihole -r
    Repair Pi-hole installation
  • pihole reloaddns
    Reload DNS settings and flush cache

File Management

  • ls -la
    List files including hidden files
  • cd DIRECTORY
    Change directory
  • nano FILE
    Edit a file using Nano
  • pwd
    Show current directory

Homelab Website Editing

  • ~/docker/webpage/html
    Website file location on Athena
  • sudo nano ~/docker/webpage/html/index.html
    Edit the homepage directly on Athena

Homelab Services

Checking on the custom scripts and APIs running behind the dashboard.

  • systemctl status calendar-sync.timer
    Confirm the calendar sync timer is active and check when it last ran
  • systemctl status calendar-sync.service
    Check the result of the most recent calendar sync run
  • journalctl -u calendar-sync.service -n 50
    View the last 50 log lines from the calendar sync script (useful for errors)
  • journalctl -u calendar-sync.service -f
    Follow the calendar sync logs live as they happen
  • curl http://localhost:5050/projects
    Quickly check that the Projects API is running and returning data

Network Troubleshooting

  • ping IP_ADDRESS
    Test network connectivity
  • curl -I WEBSITE
    Check HTTP response headers
  • ss -tlnp
    Display listening network ports
  • nslookup DOMAIN
    Test DNS resolution

Git Commands

  • git status
    Show changed files and repository status
  • git add .
    Stage all changed files for the next commit
  • git commit -m "message"
    Save a snapshot of your changes locally
  • git push
    Upload committed changes to GitHub
  • git pull
    Download the latest changes from GitHub
  • git log --oneline
    Show a compact history of commits
  • git diff
    Show what has changed since the last commit
  • git remote -v
    Display the connected GitHub repository
  • git restore FILENAME
    Discard changes to a file since the last commit
  • git restore .
    Restore all tracked files to the last committed version
