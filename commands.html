Homelab Command Reference

SSH Access

Connect to Raspberry Pis and servers remotely.

  • ssh daniel@IP_ADDRESS
    Connect to a device using SSH
  • hostname -I
    Display the current device IP address
  • hostname
    Display the device hostname

Linux System Updates

  • sudo apt update
    Refresh available package lists
  • sudo apt upgrade -y
    Install available updates
  • sudo reboot
    Restart the device

Docker Commands

  • docker ps
    Show running containers
  • docker ps -a
    Show all containers
  • docker logs CONTAINER_NAME
    View container logs
  • docker restart CONTAINER_NAME
    Restart a container
  • docker compose up -d
    Start services defined in a Docker Compose file
  • docker compose down
    Stop services defined in a Docker Compose file

NGINX Commands

  • sudo nginx -t
    Test NGINX configuration
  • sudo systemctl restart nginx
    Restart NGINX
  • sudo systemctl status nginx
    Check NGINX status
  • sudo nginx -T
    Display the complete NGINX configuration

Pi-hole Commands

  • pihole status
    Check Pi-hole status
  • pihole -up
    Update Pi-hole
  • pihole -r
    Repair Pi-hole installation
  • pihole reloaddns
    Reload DNS settings and flush cache

File Management

  • ls -la
    List files including hidden files
  • cd DIRECTORY
    Change directory
  • nano FILE
    Edit a file using Nano
  • pwd
    Show current directory

Homelab Website Editing

  • ~/docker/webpage/html
    Website file location on Athena
  • sudo nano ~/docker/webpage/html/index.html
    Edit the homepage directly on Athena

Network Troubleshooting

  • ping IP_ADDRESS
    Test network connectivity
  • curl -I WEBSITE
    Check HTTP response headers
  • ss -tlnp
    Display listening network ports
  • nslookup DOMAIN
    Test DNS resolution

Git Commands

  • git status - Show changed files and repository status.
  • git add . - Stage all changed files for the next commit.
  • git commit -m "message" - Save a snapshot of your changes locally.
  • git push - Upload committed changes to GitHub.
  • git pull - Download the latest changes from GitHub.
  • git log --oneline - Show a compact history of commits.
  • git diff - Show what has changed since the last commit.
  • git remote -v - Display the connected GitHub repository.
  • git restore filename - Discard changes to a file since the last commit.
  • git restore . - Restore all tracked files to the last committed version.
